Blockchain Forensics Platform: test data sheet

Inputs to type or upload yourself, with the result the system should give. Measured on 11 October 2026.

Before you start
  1. Use the demo platform at http://localhost:8502 and sign in as supervisor. Several results depend on its watchlist of OFAC-sanctioned addresses, so the normal platform on port 8501 will score them lower. To start it: .venv/bin/python demo/seed_demo.py, then PLATFORM_DB=data/demo.db .venv/bin/streamlit run app.py --server.port 8502.
  2. The wallets are real and the data is live, so scores can drift as the chains move. Wallets that have gone quiet (most of the sanctioned ones) stay stable. Busy exchange wallets change daily.
  3. Default bands for wallets: High ≥ 50, Medium 20–49, Low under 20. If you run the feedback-loop test, the thresholds change. Re-run the seed to reset them.
  4. Every address is a public example of a pattern, such as a sanctions listing, mixing or pass-through. It is not an accusation against its owner. All mobile-money accounts are fake TEST-ACC-… placeholders.

7. Quick checks after testing

  • Entity graph: search any address you looked up. It is now in the shared graph, with its links.
  • Audit and custody: every lookup, trace, scan and import you did is listed. "Verify chain" should report the chain intact.
  • Cases: "Open case" on any High result creates a case. Attach traced wallets as leads and decide them in the Review queue.
